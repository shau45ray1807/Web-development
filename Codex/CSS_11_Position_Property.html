// TOPIC 01 - POSITION BASICS

Position Property Kya Hai? Element page mein kahan aur kaise place hoga

Simple Definition

position CSS property decide karti hai ki element normal document flow mein rahega ya usko offset properties jaise top, right, bottom, left ke help se move kiya ja sakta hai.

Default layout mein elements normal flow follow karte hain: block elements ek ke neeche ek, inline elements line ke andar. Position property is normal flow ko control ya modify karti hai. Isse badges, tooltips, modals, sticky headers, fixed buttons, overlays aur precise UI elements banana possible hota hai.

Position Values

Value Meaning Common Use
static Default position, normal flow Normal content layout
relative Normal place se offset hota hai Small shifts, absolute child ka parent
absolute Nearest positioned ancestor ke according place hota hai Badges, tooltips, overlays
fixed Viewport ke according fixed rehta hai Fixed navbar, floating button
sticky Normal flow + scroll threshold ke baad stick Sticky header, section label
basic syntax
.box {
  position: relative;
  top: 20px;
  left: 30px;
}
■ Core Rule: top/right/bottom/left properties normally tabhi kaam karti hain jab element ka position static ke alawa kuch aur ho.
// TOPIC 02 - STATIC POSITION

position: static Default layout behavior jahan offsets ka effect nahi hota

Definition

static every element ka default position value hota hai. Static element normal document flow follow karta hai, aur top, right, bottom, left, z-index jaise positional controls normally apply nahi hote.

static example
.box {
  position: static;
  top: 40px; /* no effect */
  left: 40px; /* no effect */
}

Static Kab Use Hota Hai?

Mostly explicitly likhne ki zarurat nahi hoti, kyunki default static hi hota hai. Lekin kabhi-kabhi kisi component ka previously positioned behavior reset karna ho, to position: static useful hota hai.

// TOPIC 03 - RELATIVE POSITION

position: relative Element apni original jagah reserve rakhta hai, par visually move hota hai

Definition

relative element ko uski normal position se offset karta hai. Important baat: element ki original space document flow mein reserved rehti hai, sirf visual box move hota hai.

relative example
.badge {
  position: relative;
  top: 10px;
  left: 20px;
}

Relative Ke 2 Main Uses

SMALL VISUAL SHIFT
Kisi element ko thoda sa move karna, jaise icon alignment, badge position, decorative offset.
ABSOLUTE CHILD PARENT
Parent par position relative lagakar child ko absolute position karna. Ye most common professional pattern hai.
■ Common Confusion: Relative element move hone ke baad bhi original space occupy karta hai. Isliye next elements uski visual new position ke according adjust nahi hote.
// TOPIC 04 - ABSOLUTE POSITION

position: absolute Element normal flow se bahar nikal kar positioned ancestor ke according place hota hai

Definition

absolute element normal document flow se remove ho jata hai. Yeh apne nearest positioned ancestor ke according place hota hai. Positioned ancestor ka matlab parent/ancestor jiska position static nahi hai.

Parent Relative, Child Absolute Pattern

absolute inside relative parent
.card {
  position: relative;
}

.card-badge {
  position: absolute;
  top: 12px;
  right: 12px;
}

Absolute Element Ka Behavior

Behavior Explanation
Flow se removed Dusre elements absolute element ke liye space reserve nahi karte
Containing block Nearest non-static ancestor ke box ke according offsets apply hote hain
No positioned parent? Element initial containing block/page ke according place ho sakta hai
Precise control Badges, dropdowns, close buttons, overlays ke liye useful
■ Golden Pattern: Jis box ke andar absolute child control karna hai, us parent par usually position: relative lagao.
// TOPIC 05 - FIXED POSITION

position: fixed Element viewport ke according fixed rehta hai, page scroll se move nahi hota

Definition

fixed element viewport ke relative position hota hai. User page scroll kare, phir bhi fixed element screen par same jagah dikhta rehta hai.

fixed button
.help-button {
  position: fixed;
  right: 24px;
  bottom: 24px;
  z-index: 1000;
}

Fixed Position Use Cases

Use Case Why Fixed?
Fixed header Navigation always visible rakhna
Floating action button Important action accessible rakhna
Cookie banner Viewport bottom/top par persistent notice
Modal backdrop Entire viewport cover karna

// TOPIC 06 - STICKY POSITION

position: sticky Normal flow mein rehta hai, scroll threshold ke baad stick ho jata hai

Definition

sticky relative aur fixed ka combination jaisa behave karta hai. Element pehle normal flow mein hota hai, phir scroll karte waqt specified offset, jaise top: 0, par pahunchne ke baad stick ho jata hai.

sticky header
.section-title {
  position: sticky;
  top: 0;
  z-index: 10;
}
sticky scroll demo
STICKY HEADER - top: 0

Scroll container ke andar ye header top par stick rahega.

Sticky element normal flow se start hota hai.

Jab top edge threshold touch karta hai, tab sticky behavior start hota hai.

Sticky parent/scroll container ke boundary ke andar hi kaam karta hai.

Agar parent ki height enough nahi hai, sticky clearly visible nahi hoga.

Section headings, tables ke column headers, app sidebars mein useful hai.

Sticky ke liye top/bottom/left/right offset define karna zaruri hota hai.

Sticky Not Working? Check This

Problem Fix
top set nahi hai top: 0 ya required offset add karo
Parent height enough nahi Scrollable space ensure karo
Ancestor overflow hidden/auto Scroll container behavior samjho aur test karo
z-index low hai Overlapping content ke liye z-index set karo
// TOPIC 07 - OFFSET PROPERTIES

top, right, bottom, left and inset Positioned element ko exact direction mein move/place karna

top, right, bottom, left offset properties hain. Inka meaning position value par depend karta hai. Relative mein ye original position se shift karte hain; absolute/fixed mein containing block/viewport ke edges se distance define karte hain.

Property Meaning
top Top edge se distance ya original position se downward shift
right Right edge se distance
bottom Bottom edge se distance
left Left edge se distance ya original position se right shift
inset top/right/bottom/left ka shorthand

inset Shorthand

inset examples
.overlay {
  position: fixed;
  inset: 0; /* top/right/bottom/left: 0 */
}

.panel {
  position: absolute;
  inset: 20px 30px auto auto;
}
■ Clean Code Tip: Full-screen overlay ke liye inset: 0 very clean shorthand hai. Ye top: 0; right: 0; bottom: 0; left: 0; ke equal hai.
// TOPIC 08 - Z-INDEX

z-index and Layering Kaunsa element upar dikhega aur kaunsa neeche

Definition

z-index positioned elements ki stacking order control karta hai. Higher z-index wala element same stacking context mein lower z-index wale element ke upar dikhta hai.

z-index layering demo
z-index: 1
z-index: 3
z-index: 2
z-index example
.modal {
  position: fixed;
  z-index: 1000;
}

.tooltip {
  position: absolute;
  z-index: 20;
}

Stacking Context Simple Samajh

Kabhi-kabhi high z-index dene ke baad bhi element upar nahi aata. Reason hota hai stacking context. Parent elements apna separate layer group bana sakte hain. Child ka z-index us parent context ke bahar compete nahi kar pata.

■ Practical Habit: Random huge values like 999999 use karne ke bajay app ke layers plan karo: dropdown 100, header 500, modal 1000, toast 1100.

Practical Position Patterns Badges, close buttons, overlays, center modals aur sticky nav

Full Screen Modal Overlay

modal overlay
.overlay {
  position: fixed;
  inset: 0;
  display: grid;
  place-items: center;
  background: rgba(0, 0, 0, 0.6);
  z-index: 1000;
}

Centered Absolute Element

absolute center
.centered {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
}
■ Modern Tip: Centering ke liye fixed/absolute + transform common hai, but many cases mein display: grid; place-items: center; simpler hota hai.
// TOPIC 10 - COMMON MISTAKES

Common Mistakes and Fixes Position bugs ko quickly identify karna

MISTAKE
Absolute child ka parent relative set na karna.
Normal layout ke liye position use karna.
Fixed header content ko cover kar raha hai.
Sticky element par top offset na dena.
z-index huge values randomly use karna.
Relative element ki reserved space bhool jana.
FIX
Parent par position: relative lagao.
Normal layout ke liye flex/grid use karo.
Content padding/margin top adjust karo.
sticky ke saath top/right/bottom/left set karo.
Layer scale plan karo: 10, 100, 1000.
Relative ko visual offset only samjho.

Debugging Checklist

Check Question
Position value Kya element static hai? Offsets kaam karenge?
Containing block Absolute element kis parent ke according position ho raha hai?
Document flow Kya element flow se remove ho gaya hai?
Sticky condition top offset, scroll space aur parent overflow correct hai?
Layering z-index same stacking context mein compare ho raha hai?
Mobile view Fixed/absolute element small screen par content cover kar raha hai?
■ Big Rule: Position layout system ka replacement nahi hai. Page structure ke liye Flexbox/Grid use karo; precise overlay/edge placement ke liye position use karo.

Fast Decision Guide

Need Choose
Normal layout banana hai Flexbox/Grid, position nahi
Child ko card ke corner mein place karna hai Parent relative + child absolute
Element screen par fixed chahiye position: fixed
Header scroll ke baad stick chahiye position: sticky + top
Full screen overlay banana hai position: fixed + inset: 0
Element ko dusre ke upar dikhana hai z-index + stacking context check

Best Practices - Yaad Rakhna

DO
Parent-child positioning relation clear rakho.
Absolute child ke parent par relative lagao.
Sticky ke saath top offset define karo.
Fixed elements ke liye content spacing plan karo.
z-index scale maintain karo.
Mobile screen par positioned UI test karo.
AVOID
Whole page layout absolute se banana.
Random z-index 999999 use karna.
Parent relative bhool jana.
Fixed elements se content cover karna.
Sticky without top offset.
Relative offset ko real layout shift samajhna.
