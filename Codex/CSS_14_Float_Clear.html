// TOPIC 01 - FLOAT BASICS

float Property Kya Hai? Element ko left/right side par push karke text ko uske around flow karwana

Simple Definition

float CSS property element ko normal flow se partially remove karke left ya right side par place karti hai, aur nearby inline/text content uske around wrap kar sakta hai. Iska original use images ke around text flow karwana tha.

Old CSS days mein float ko page layout banane ke liye bhi use kiya jaata tha, jaise two-column layouts. Lekin modern CSS mein layout ke liye Flexbox aur Grid better hain. Float aaj bhi useful hai jab image, quote, icon ya small box ke around paragraph text wrap karwana ho.

float Values

Value Meaning Use
none Default, element float nahi karega Normal document flow
left Element container ke left side float karega Image left, text right side wrap
right Element container ke right side float karega Image right, text left side wrap
inline-start Writing direction ke start side par float Logical direction layouts
inline-end Writing direction ke end side par float Internationalized layouts
basic float syntax
.image {
  float: left;
  width: 160px;
  margin-right: 16px;
}
■ Core Idea: Float ka main purpose text wrapping hai. Full page layout ke liye float old technique hai; modern layout ke liye Flexbox/Grid use karo.
// TOPIC 02 - FLOAT LEFT

float: left Element left side par chala jaata hai aur text right side wrap karta hai

Definition

float: left element ko parent container ke left edge ki taraf float karta hai. Uske baad jo text ya inline content aata hai, woh element ke right side se flow kar sakta hai.

float left demo
float: left
Float left use karne par ye box left side par placed hai. Paragraph ka text box ke right side mein wrap ho raha hai. Ye pattern article image, author avatar, drop cap style blocks aur small illustrations ke liye useful ho sakta hai. Margin dena important hai, warna text floated element se chipak jaata hai.
float left image
.article-img {
  float: left;
  width: 180px;
  margin: 0 18px 12px 0;
}
■ Spacing Tip: Left floated element ke liye usually right aur bottom margin dete hain, taaki text element se touch na kare.
// TOPIC 03 - FLOAT RIGHT

float: right Element right side par chala jaata hai aur text left side wrap karta hai

Definition

float: right element ko parent container ke right edge ki taraf float karta hai. Nearby text uske left side se flow karta hai.

float right demo
float: right
Float right use karne par box right side par placed hai. Text left side se flow hota hai aur available space ke according wrap karta hai. Ye pattern pull quote, article thumbnail, small badge ya side image ke liye kaam aa sakta hai. Responsive screen par float behavior carefully test karna chahiye.
float right box
.quote-box {
  float: right;
  width: 220px;
  margin: 0 0 14px 18px;
}
■ Mobile Warning: Small screens par floated boxes text ko very narrow bana sakte hain. Media query mein float remove karna common solution hai.
// TOPIC 04 - CLEAR PROPERTY

clear Property Element ko floated elements ke neeche force karna

Simple Definition

clear property batati hai ki element ke left/right side par floated elements allowed hain ya nahi. Agar clear: both diya, to element previous left/right floats ke neeche start hoga.

clear Values

Value Meaning Use
none Default, floats ke side mein aa sakta hai Normal behavior
left Left floated elements ke neeche start Left float stop karna
right Right floated elements ke neeche start Right float stop karna
both Left and right floats dono ke neeche start Most common clear value
clear both demo
float left
float right
Yeh text floats ke beech available space mein flow kar raha hai. Lekin next block agar normal flow mein aaye to woh floats ke side mein aa sakta hai.
clear: both; this line starts below floated boxes
clear both
.next-section {
  clear: both;
}
// TOPIC 05 - PARENT COLLAPSE

Parent Collapse Problem Floated children parent ki height mein count nahi hote

Important Problem

Jab parent ke andar sirf floated children hote hain, parent ki height collapse ho sakti hai. Reason: floated elements normal flow se remove jaise behave karte hain, isliye parent unki height automatically include nahi karta.

collapse example
.parent {
  border: 2px solid red;
}

.child {
  float: left;
  width: 100px;
  height: 100px;
}
collapsed parent concept
Parent border collapse/short dikh sakta hai jab andar ke elements float ho aur normal content na ho. Is problem ko solve karne ke liye clearfix, overflow auto, display flow-root, ya modern layout use kiya ja sakta hai.
■ Common Bug: Parent background/border missing lag raha hai? Check karo andar ke children float hain kya. Agar haan, parent collapse likely issue hai.
// TOPIC 06 - CLEARFIX

Clearfix Technique Parent ko floated children ki height include karwana

Definition

Clearfix ek CSS technique hai jisme parent ke after pseudo-element ko clear kiya jaata hai. Isse parent floated children ki height contain kar leta hai.

classic clearfix
.clearfix::after {
  content: "";
  display: block;
  clear: both;
}
clearfix demo
float child
Parent par clearfix applied hai. Isliye floated child ke baad parent ka height properly contain hota hai. Yeh old float-based layouts mein bahut common solution tha.

Modern Alternative: flow-root

flow-root contain floats
.parent {
  display: flow-root;
}
■ Modern Tip: New code mein parent float containment ke liye display: flow-root clearfix se cleaner ho sakta hai.
// TOPIC 07 - FLOAT WITH IMAGES

Image Text Wrap Pattern Float ka real useful modern use case

Float ka sabse natural use article image ko left/right side par rakhkar text ko uske around wrap karwana hai. Ye magazine/newspaper style layout ke liye useful hota hai.

article image wrap demo
CSS float image ko paragraph ke side mein place karta hai. Text image ke around wrap hota hai, isliye content natural article flow jaisa lagta hai. Agar image important hai, alt text HTML mein dena zaruri hai. Agar image decorative hai, accessible handling different ho sakti hai.
article image wrap
<img class="article-img" src="photo.jpg" alt="...">
<p>Article text image ke around wrap hoga...</p>
image css
.article-img {
  float: left;
  max-width: 40%;
  margin: 0 1rem 0.75rem 0;
}

@media (max-width: 600px) {
  .article-img {
    float: none;
    max-width: 100%;
    margin: 0 0 1rem;
  }
}
// TOPIC 08 - FLOAT VS MODERN LAYOUT

Float vs Flexbox/Grid Kab float use karein aur kab modern layout use karein

Modern Rule

Float ko layout system ke replacement ke roop mein use nahi karna chahiye. Columns, navbars, cards, dashboards aur page layouts ke liye Flexbox aur CSS Grid zyada predictable, responsive aur maintainable hain.

Need Use Float? Better Choice
Text image ke around wrap karna Yes float
Navbar links align karna No Flexbox
Two-column page layout No for new code Grid or Flexbox
Card grid banana No CSS Grid
Small pull quote side mein rakhna Maybe float or grid depending design
modern columns
.layout {
  display: grid;
  grid-template-columns: 240px 1fr;
  gap: 24px;
}
■ History Note: Float layouts important historical CSS topic hain. Legacy projects samajhne ke liye float/clear knowledge useful hai.
// TOPIC 09 - COMMON MISTAKES

Common Mistakes and Fixes Float bugs ko quickly identify karna

MISTAKE
Page layout ke liye float use karna.
Float ke baad clear na lagana.
Parent collapse problem ignore karna.
Floated image ko margin na dena.
Mobile screen par float remove na karna.
Clearfix ke purpose ko samjhe bina copy karna.
FIX
Layout ke liye Flexbox/Grid use karo.
Next section par clear: both use karo where needed.
Parent par clearfix ya flow-root use karo.
Float side ke opposite margin add karo.
Media query mein float: none karo.
Float containment ka concept samjho.

Debugging Checklist

Check Question
Float direction Element left float hai ya right?
Spacing Text aur floated element ke beech margin hai?
Clear Next content ko float ke neeche start hona chahiye?
Parent height Parent collapse ho raha hai?
Responsive Mobile par float layout readable hai?
Modern alternative Kya ye layout Flexbox/Grid se better ban sakta hai?
■ Big Rule: Float ko layout shortcut mat banao. Float ka use tab karo jab content ko floated element ke around wrap karwana ho.
