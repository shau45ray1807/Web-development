// TOPIC 01 - GRID BASICS

CSS Grid Kya Hai? Two-dimensional layout system for rows and columns

Simple Definition

CSS Grid ek powerful layout system hai jo rows aur columns dono ko ek saath control karta hai. Flexbox mostly one-dimensional layout ke liye best hai, jabki Grid two-dimensional page/layout structure ke liye best hai.

Grid se card galleries, dashboards, page shells, image layouts, magazine layouts, forms, product listings aur complex responsive sections clean CSS se ban sakte hain. Grid parent par display: grid lagta hai aur uske direct children grid items ban jaate hain.

first grid
.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 1rem;
}

// TOPIC 04 - FR, REPEAT, MINMAX

fr, repeat() and minmax() Grid ka responsive sizing toolkit

Important Tools

fr available free space ko fractions mein divide karta hai. repeat() repeated tracks ko short banata hai. minmax() track ko flexible min/max range deta hai.

fr repeat minmax
.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
}

.responsive-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
}
Expression Meaning
1fr Available space ka 1 fraction
2fr 1fr se double share
repeat(4, 1fr) 4 equal flexible columns
minmax(200px, 1fr) Minimum 200px, max available flexible space
repeat(auto-fit, minmax(220px, 1fr)) Responsive columns without many media queries
■ Power Pattern: repeat(auto-fit, minmax(250px, 1fr)) responsive card grids ke liye top-level professional pattern hai.

// TOPIC 08 - IMPLICIT GRID

Explicit and Implicit Grid Defined tracks aur automatically created tracks

Definition

Explicit grid woh hoti hai jo hum grid-template-columns aur grid-template-rows se define karte hain. Agar extra items ya placement defined grid se bahar chala jaaye, browser implicit tracks create karta hai.

implicit rows
.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-auto-rows: 120px;
  grid-auto-flow: row;
}
Property Use
grid-auto-rows Implicit rows ka size define karta hai
grid-auto-columns Implicit columns ka size define karta hai
grid-auto-flow Auto placement row, column, dense behavior control karta hai
■ Advanced Note: grid-auto-flow: dense gaps fill kar sakta hai, but visual order change ho sakta hai. Accessibility and reading order carefully test karo.

// TOPIC 11 - GRID VS FLEXBOX

Grid vs Flexbox Kaunsa layout system kab choose karein

Simple Decision

Flexbox one-dimensional flow ke liye best hai: row ya column. Grid two-dimensional structure ke liye best hai: rows and columns together. Dono competitors nahi, partners hain.

Need Choose Reason
Navbar links Flexbox One row alignment
Button group Flexbox Inline distribution
Product card grid Grid Rows and columns
Dashboard page Grid Named areas and 2D control
Card internal layout Flexbox Vertical item spacing/button bottom
Outer page shell Grid Header/sidebar/main/footer structure
■ Professional Pattern: Outer layout Grid se banao, component ke andar alignment Flexbox se. Ye combination very common hai.
// TOPIC 12 - ADVANCED GRID

Advanced Grid Concepts Named lines, fit-content, masonry thinking, subgrid and dense flow

Named Grid Lines

named lines
.layout {
  display: grid;
  grid-template-columns: [sidebar-start] 240px [sidebar-end content-start] 1fr [content-end];
}

.main {
  grid-column: content-start / content-end;
}

fit-content and clamp-like Sizing

fit content
.grid {
  grid-template-columns: fit-content(260px) 1fr;
}

Subgrid

subgrid child grid ko parent grid ke tracks inherit karne deta hai. Yeh advanced layout alignment ke liye useful hai, especially cards/forms mein jahan nested content parent columns align kare.

subgrid idea
.card {
  display: grid;
  grid-template-rows: subgrid;
}
■ Advanced Note: Subgrid modern feature hai. Use karte time browser support check karna good habit hai.
// TOPIC 13 - COMMON MISTAKES

Common Mistakes and Fixes Grid bugs ko quickly identify karna

MISTAKE
Grid items direct children rule bhoolna.
Line numbers tracks samajh lena.
fr unit ko percentage samajhna.
grid-template-areas mein broken shape banana.
Fixed columns se mobile overflow karna.
Flexbox ka kaam Grid se force karna.
align-items vs align-content confuse karna.
FIX
Direct children inspect karo.
Lines always tracks se one extra hoti hain.
fr available free space share karta hai.
Areas rectangle shape mein rakho.
minmax and auto-fit responsive pattern use karo.
One-dimensional layouts ke liye Flexbox use karo.
Item alignment and grid alignment separate samjho.

Debugging Checklist

Check Question
Container Kya parent par display: grid laga hai?
Direct child Kya item grid container ka direct child hai?
Tracks Columns/rows expected size define hain?
Lines grid-column line numbers correct hain?
Areas Template area names match kar rahe hain?
Responsive Small screen par minmax/auto-fit ya media query needed hai?
Overflow Any fixed width track page ko side-scroll kara raha hai?
■ Big Rule: Grid ko tab use karo jab rows and columns ka structure important ho. Simple single-axis alignment ke liye Flexbox zyada natural ho sakta hai.
