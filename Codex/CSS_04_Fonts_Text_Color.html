// TOPIC 01 - FONT PROPERTIES

CSS Font Properties Website ke letters ka family, size, weight aur style control karna

KYA HAI?

Font properties se hum text ka typeface, size, thickness, style aur reading flow control karte hain. Simple words mein: font properties decide karti hain ki text kaise dikhega aur padhne mein kitna comfortable hoga.

1. font-family - Font Ka Naam

font-family batata hai browser ko ki text kis font mein show karna hai. Always backup fonts bhi do, kyunki user ke system mein first font available na ho sakta hai.

Browser font ko left se right check karta hai. Agar first font available hai toh wahi use hoga. Agar first font missing hai toh second font use hoga. Agar wo bhi missing hai toh generic family jaise sans-serif ya serif use hogi. Isi backup system ko font stack bolte hain.

font-family.css
/* Font family - pehle preferred font, phir fallback fonts */
body {
    font-family: Arial, Helvetica, sans-serif;
}

h1 {
    font-family: 'Times New Roman', Times, serif;
}

code {
    font-family: 'Courier New', monospace;
}
SERIF
Letters ke ends par chhoti strokes hoti hain. Example: Times New Roman, Georgia. Books aur formal text mein common.
SANS-SERIF
Clean letters, extra strokes nahi. Example: Arial, Helvetica, Poppins. Websites mein sabse zyada use hota hai.
Generic Family Look Use Case
serif Letters ke end par strokes Books, formal articles, editorial layout
sans-serif Clean aur modern letters Websites, apps, dashboards, landing pages
monospace Har letter ki width same Code blocks, terminal, technical notes
cursive Handwriting style Decorative headings, invitations
fantasy Highly decorative Rare use, poster type design
■ Deep Point: Jis font name mein space ho, usko quotes mein likhna hota hai. Example: 'Times New Roman'. Single word font jaise Arial bina quotes ke bhi chal jaata hai.

2. font-size - Text Ka Size

font-size text ki height/size decide karta hai. Website readability ka sabse direct effect isi property se hota hai. Agar text chhota hai toh user ko padhne mein strain hoga; agar text bahut bada hai toh layout heavy aur unbalanced lagega.

CSS mein font-size fixed bhi ho sakta hai aur relative bhi. Fixed means exact value, jaise 16px . Relative means kisi existing size ke according, jaise 1rem root font-size ke according aur 1.2em parent ke according.

font-size.css
/* Fixed size */
p {
    font-size: 16px;
}

/* Relative size - responsive design ke liye better */
h1 {
    font-size: 2.5rem;  /* root font size ka 2.5 times */
}

small {
    font-size: 0.875rem;
}
Unit Example Kab Use Kare?
px 16px Exact fixed size chahiye ho
rem 1.5rem Most recommended for font sizes
em 1.2em Parent ke font size ke according
% 120% Parent size ka percentage

font-size Units Ko Proper Samjho

size-units-explained.css
/* Default browser root font-size usually 16px hota hai */
html {
    font-size: 16px;
}

.title {
    font-size: 2rem;     /* 2 x 16px = 32px */
}

.card {
    font-size: 20px;
}

.card p {
    font-size: 1.2em;    /* 1.2 x parent 20px = 24px */
}
■ Pro Tip: Normal paragraph text ke liye mostly 16px ya 1rem comfortable hota hai. Headings ke liye rem use karo, responsive design clean rahega.

3. font-weight - Text Ki Thickness

font-weight text ko light, normal, semi-bold, bold ya extra-bold banata hai. Headings mein usually heavier weight use hota hai taaki hierarchy clear ho. Paragraph text mein normal ya medium weight use hota hai taaki long reading comfortable rahe.

font-weight.css
/* Keyword values */
p      { font-weight: normal; }  /* 400 */
strong { font-weight: bold;   }  /* 700 */

/* Numeric values */
.light  { font-weight: 300; }
.normal { font-weight: 400; }
.medium { font-weight: 500; }
.bold   { font-weight: 700; }
.black  { font-weight: 900; }
Value Name Common Use
100 Thin Rare, decorative large headings
300 Light Subtle headings, elegant design
400 Normal Paragraphs, default text
500 Medium Labels, buttons, nav links
600 Semi Bold Sub-headings, card titles
700 Bold Main headings, important text
900 Black Hero headings, poster-style text
■ Important: Har font family har weight support nahi karti. Agar font ke paas 600 weight file nahi hai toh browser nearest available weight use karega. Isliye Google Fonts se required weights load karna zaroori hai.

4. font-style aur font-variant

font-style ka most common use italic text ke liye hota hai. Italic usually emphasis, quotes, technical terms ya special words ko highlight karne ke liye use hota hai. font-variant: small-caps normal lowercase letters ko capital-style small letters jaisa dikhata hai.

font-style.css
em {
    font-style: italic;       /* slanted text */
}

.no-italic {
    font-style: normal;       /* italic remove */
}

.small-caps {
    font-variant: small-caps;   /* lowercase bhi capital style mein */
}

5. line-height - Lines Ke Beech Space

line-height reading comfort ke liye bahut important hai. Agar line-height tight hai toh text crowded lagega, aur zyada hai toh text disconnected lagega.

Line-height actual text size ke upar extra vertical space add karta hai. Example: agar font-size: 16px aur line-height: 1.6 hai, toh ek line ki total height around 25.6px hogi. Unitless value best hoti hai kyunki child elements apne font-size ke according line-height calculate kar lete hain.

line-height.css
p {
    font-size:   16px;
    line-height: 1.6;    /* best practice - unitless value */
}

h1 {
    line-height: 1.1;    /* headings ko compact rakhte hain */
}
■ Note: Paragraphs ke liye line-height: 1.5 se 1.8 usually best hota hai. Headings ke liye 1.1 se 1.3 clean lagta hai.

6. Font Inheritance - Parent Se Child Tak

Most font properties inherited hoti hain. Matlab agar body par font-family, font-size, line-height aur color set kar diya, toh andar ke paragraph, list, span jaise elements automatically wahi style follow karenge, jab tak unke liye alag CSS na likhi ho.

inheritance.css
body {
    font-family: 'Poppins', sans-serif;
    font-size:   16px;
    line-height: 1.6;
    color:       #222;
}

/* p ko font-family alag se dene ki zaroorat nahi,
   kyunki body se inherit ho jayega */
p {
    margin-bottom: 16px;
}
// TOPIC 02 - TEXT PROPERTIES

CSS Text Properties Text ka alignment, decoration, spacing, case aur shadow control karna

KYA HAI?

Text properties se hum letters ka font nahi, balki text ka arrangement aur presentation control karte hain. Jaise text center ho ya left, underline ho ya nahi, uppercase ho ya lowercase, letters ke beech kitna gap ho, etc.

1. text-align - Text Ki Direction / Alignment

text-align text ko horizontal direction mein align karta hai. Yeh property mostly block-level elements par useful hoti hai, jaise p, div, h1, section. Agar tum inline element jaise span par text-align lagao, toh usually visible effect nahi dikhega kyunki inline element apni content width jitna hi space leta hai.

text-align.css
h1 {
    text-align: center;
}

p {
    text-align: left;      /* default in English/Hinglish */
}

.price {
    text-align: right;     /* tables/prices ke liye useful */
}

.article {
    text-align: justify;   /* both sides equal line edge */
}
■ Warning: Long paragraphs ko mobile par justify karne se weird gaps aa sakte hain. Websites mein normal readable text ke liye left alignment safest hota hai.
Value Meaning Example Use
left Text left side se start hota hai Articles, paragraphs, forms
center Text center mein aata hai Hero heading, cards, short labels
right Text right side align hota hai Prices, table numbers, invoices
justify Line dono sides se equal stretch hoti hai Print-like layout, newspapers
start Writing direction ke start side par Multilingual websites
end Writing direction ke end side par RTL/LTR adaptive layouts

2. text-decoration - Underline / Overline / Strike

text-decoration text ke upar, neeche ya beech mein line add karta hai. Links mein browser default underline deta hai. Hum underline remove bhi kar sakte hain, ya modern CSS se underline ka color, thickness aur style customize kar sakte hain.

text-decoration.css
/* Links ki underline remove */
a {
    text-decoration: none;
}

/* Modern detailed decoration */
.special-link {
    text-decoration-line:  underline;
    text-decoration-color: #00b4d8;
    text-decoration-style: wavy;
    text-decoration-thickness: 2px;
}

.old-price {
    text-decoration: line-through;
}
■ Link Note: Agar links ki underline remove kar rahe ho, toh hover/focus par koi clear visual signal do. Sirf color change kabhi-kabhi enough nahi hota, especially accessibility ke liye.

3. text-transform - Case Change

text-transform actual HTML text ko change nahi karta, sirf browser mein display ka case change karta hai. Iska benefit yeh hai ki content clean rehta hai aur CSS se design control hota hai. Example: HTML mein "submit form" likha hai, CSS se button par "SUBMIT FORM" dikh sakta hai.

text-transform.css
.title {
    text-transform: uppercase;    /* HELLO WORLD */
}

.name {
    text-transform: capitalize;   /* Hello World */
}

.quiet {
    text-transform: lowercase;    /* hello world */
}
■ Tip: HTML content ko manually uppercase type mat karo. CSS mein text-transform: uppercase use karo, taaki screen readers aur copy-paste behavior better rahe.

4. letter-spacing aur word-spacing

letter-spacing letters ke beech ka gap control karta hai. Yeh badges, nav labels, uppercase headings jaise short text par achha lagta hai. Lekin paragraph text par zyada letter-spacing readability kharab kar sakti hai.

word-spacing words ke beech ka gap control karta hai. Iska use rare hota hai, kyunki default spacing usually readable hoti hai. Special typography effects ya wide layout mein use kar sakte hain.

spacing.css
.badge {
    letter-spacing: 3px;
    text-transform: uppercase;
}

.para {
    word-spacing: 4px;
}

.compact {
    letter-spacing: normal;
    word-spacing:   normal;
}
■ Common Mistake: Uppercase text ke saath thoda letter-spacing achha lagta hai, lekin normal paragraph mein letter-spacing: 3px jaisa large value text ko difficult bana deta hai.

5. text-indent, white-space aur overflow

text-indent first line ko left se andar shift karta hai. Books aur articles mein paragraph starting show karne ke liye use hota hai. Web design mein margin/padding zyada common hai, but long reading layouts mein text-indent useful ho sakta hai.

white-space decide karta hai ki spaces, tabs aur line breaks kaise handle honge. Normal text automatically wrap hota hai, lekin code, file paths, single-line labels ya chips mein wrapping control karna padta hai.

text-flow.css
.article p {
    text-indent: 40px;       /* paragraph ki first line andar */
}

.single-line {
    white-space: nowrap;     /* text next line pe nahi jayega */
    overflow: hidden;
    text-overflow: ellipsis; /* extra text ... ban jayega */
}

pre {
    white-space: pre-wrap;   /* spaces preserve + line wrap */
}
white-space Value Spaces Preserve? Line Wrap? Use
normal No Yes Default paragraphs
nowrap No No Single-line labels, nav items
pre Yes No Exact formatted text
pre-wrap Yes Yes Code/text preserving spaces but wrapping
pre-line Line breaks yes Yes User-entered multi-line text
■ Ellipsis Rule: text-overflow: ellipsis tabhi kaam karta hai jab element ki fixed/limited width ho, overflow: hidden ho, aur text single line ho with white-space: nowrap.

6. text-shadow - Text Ke Peeche Shadow

text-shadow text ke peeche shadow ya glow effect create karta hai. Ismein 4 cheezein hoti hain: horizontal offset, vertical offset, blur radius aur color. Positive x shadow ko right le jaata hai, positive y shadow ko down le jaata hai, blur shadow ko soft karta hai.

text-shadow.css
/* text-shadow: x-offset y-offset blur color; */
h1 {
    text-shadow: 2px 2px 6px rgba(0, 0, 0, 0.4);
}

.glow {
    color: #00b4d8;
    text-shadow: 0 0 12px rgba(0, 180, 216, 0.8);
}
Text Property Demo
text-align: center;Yeh text center aligned hai
uppercase + letter-spacingImportant Badge Text
text-shadow glowGlowing heading effect

7. Text Properties Ka Real Use Case

Real website mein text properties ko isolated use nahi karte. Usually heading ke liye text-transform, letter-spacing, font-weight aur line-height saath use hote hain. Paragraph ke liye font-size, line-height, color aur max-width reading comfort decide karte hain.

article-text-system.css
.article {
    max-width: 720px;
}

.article h2 {
    font-size: 2rem;
    line-height: 1.2;
    text-transform: capitalize;
}

.article p {
    font-size: 1rem;
    line-height: 1.75;
    color: #4b5563;
}
// TOPIC 03 - COLOR PROPERTIES

CSS Color Properties Text, background, border aur transparency ke colors control karna

KYA HAI?

Color properties se hum kisi bhi element ka text color, background color, border color, shadow color aur transparency set karte hain. CSS mein colors multiple formats mein likh sakte hain: name, HEX, RGB, RGBA, HSL, HSLA.

1. color - Text Ka Color

color property element ke text ka color set karti hai. Yeh inherited property hai, matlab agar parent element par color set hai toh child text bhi wahi color inherit kar sakta hai. Isi wajah se hum often body par base text color set kar dete hain.

color.css
h1 {
    color: white;
}

p {
    color: #a8b2d8;
}

.error {
    color: rgb(233, 69, 96);
}
color-inheritance.css
body {
    color: #1f2937;  /* website ka default text color */
}

.card {
    color: #e8eaf6;  /* card ke andar ka text inherit karega */
}

.card a {
    color: #00b4d8;  /* link ka color specifically override */
}

2. background-color - Element Ka Background

background-color element ke background area ko fill karta hai. Yeh text ke peeche ka color hota hai. Button, card, navbar, footer, alert box, highlight section, badge - sab mein background-color ka heavy use hota hai.

background-color.css
body {
    background-color: #0a0f1e;
}

.card {
    background-color: #0d1b2a;
}

.highlight {
    background-color: yellow;
    color: black;
}
■ Note: color sirf text color change karta hai. background-color element ke background ko color deta hai. Dono ko mix karte time contrast ka dhyan rakho.

3. Color Formats in CSS

CSS colors ko multiple formats mein likh sakte hain. Output same ho sakta hai, bas writing style different hota hai. Beginners ke liye HEX easiest hota hai, RGB transparency ke liye useful hota hai, aur HSL color variations create karne ke liye bahut readable hota hai.

Format Example Explanation
Color Name red Simple predefined color name
HEX #e94560 Most common web color format
RGB rgb(233, 69, 96) Red, Green, Blue values 0-255
RGBA rgba(233, 69, 96, 0.5) RGB + alpha transparency
HSL hsl(350, 80%, 59%) Hue, Saturation, Lightness
HSLA hsla(350, 80%, 59%, 0.5) HSL + alpha transparency
color-formats.css
.name { color: crimson; }
.hex  { color: #e94560; }
.rgb  { color: rgb(233, 69, 96); }
.rgba { color: rgba(233, 69, 96, 0.7); }
.hsl  { color: hsl(350, 80%, 59%); }

HEX, RGB aur HSL Ko Detail Mein Samjho

HEX
HEX format #RRGGBB hota hai. Pehle 2 digits red, next 2 green, last 2 blue. Example #ffffff white, #000000 black. Short form bhi hota hai: #fff.
RGB / RGBA
RGB mein red, green, blue values 0 se 255 tak hoti hain. RGBA mein last value alpha hoti hai, jahan 0 fully transparent aur 1 fully visible hota hai.
HSL
HSL means Hue, Saturation, Lightness. Hue color wheel angle hai, saturation color ki intensity hai, lightness color ko dark/light banata hai.
Alpha
Alpha transparency control karta hai. Modern CSS mein rgb(0 0 0 / 0.5) aur hsl(220 80% 50% / 0.4) syntax bhi use hota hai.
modern-color-syntax.css
.overlay {
    background: rgb(0 0 0 / 0.6);       /* modern RGB alpha */
}

.tag {
    background: hsl(190 100% 42% / 0.15);
    color:      hsl(190 100% 42%);
}

4. border-color aur outline-color

border-color element ke border ka color set karta hai. Border tabhi dikhega jab border style aur width bhi set ho. Sirf border-color likhne se border visible nahi hota agar border style missing hai.

outline border jaisa dikhta hai, lekin layout space occupy nahi karta. Forms, buttons aur links ke focus state mein outline important hota hai. Keyboard se website use karne wale users isi outline se samajhte hain ki current focus kahan hai.

border-outline-color.css
.card {
    border: 1px solid #1e3a5f;
}

input:focus {
    outline: 2px solid #00b4d8;
    outline-offset: 2px;
}
■ Accessibility Tip: Focus outline ko remove mat karo jab tak uska clear replacement na ho. Keyboard users ko pata chalna chahiye ki currently kaunsa element selected hai.

5. opacity - Whole Element Transparent

opacity element ki overall visibility control karta hai. Value 0 ka matlab fully invisible, 1 ka matlab fully visible. Beech ki values like 0.5 element ko 50% transparent bana deti hain.

opacity.css
.disabled {
    opacity: 0.5;        /* element + text + children sab fade */
}

.overlay {
    background: rgba(0, 0, 0, 0.6);  /* sirf background transparent */
}
■ Important: opacity poore element ko transparent karta hai, including text aur child elements. Agar sirf background transparent chahiye toh rgba() ya hsla() use karo.

6. currentColor - Text Color Ko Reuse Karna

currentColor ek special CSS keyword hai jo current element ke color value ko reuse karta hai. Isse border, icon, outline ya shadow ko same color dena easy ho jaata hai. Buttons aur icon links mein yeh bahut useful hai.

current-color.css
.btn {
    color: #00b4d8;
    border: 2px solid currentColor;  /* border bhi text color jaisa */
}

.btn:hover {
    color: #06d6a0;                  /* border automatically green */
}

7. CSS Variables For Colors

Real projects mein same colors baar-baar use hote hain. Agar har jagah direct #e94560 likhoge toh later brand color change karna difficult hoga. CSS variables se color ek jagah define karte hain aur poori website mein reuse karte hain.

color-variables.css
:root {
    --primary: #00b4d8;
    --danger:  #e94560;
    --text:    #e8eaf6;
    --surface: #0d1b2a;
}

body {
    color: var(--text);
}

.card {
    background: var(--surface);
    border-color: var(--primary);
}
■ Pro Tip: Color variables ko meaningful naam do, jaise --primary, --text, --surface. Sirf --blue naam rakhoge toh future mein color blue se purple ho gaya toh naam confusing ho jayega.

8. Contrast - Readability Ka Rule

Color choose karte time sabse important cheez contrast hai. Light background par dark text readable hota hai; dark background par light text readable hota hai. Low contrast text stylish lag sakta hai, lekin padhne mein difficult hota hai, especially mobile screen, sunlight ya weak eyesight users ke liye.

GOOD CONTRAST
Dark background + light text. Reading clear, accessible, comfortable.
LOW CONTRAST
Dark background + dark text. Stylish ho sakta hai, par readable nahi.
// TOPIC 04 - PRACTICAL TYPOGRAPHY

Google Fonts, @font-face aur Font Shorthand Real projects mein custom fonts kaise use karte hain

KYA HAI?

Default fonts ke alawa hum custom fonts bhi use kar sakte hain. Most beginners ke liye Google Fonts easiest option hai. Advanced projects mein local font files ke liye @font-face use hota hai.

1. Google Fonts Use Karna

Google Fonts se custom fonts use karna beginner-friendly hai. Website se font select karo, required weights choose karo, phir generated <link> tag HTML ke <head> mein paste karo. Uske baad CSS mein font-family set kar do.

Font load hone mein thoda time lag sakta hai. Isi liye Google Fonts URL mein display=swap hota hai. Iska matlab: jab tak custom font load nahi hota, browser fallback font show karega; font load hone ke baad custom font swap ho jayega.

google-fonts.html
<!-- HTML head ke andar Google Font link add karo -->
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Poppins:wght@400;600;700&display=swap" rel="stylesheet">
use-google-font.css
body {
    font-family: 'Poppins', sans-serif;
}
■ Pro Tip: Google Fonts se sirf wahi weights load karo jo use karne wale ho. Example: 400;600;700. Extra weights website ko slow kar sakte hain.

2. @font-face - Local Font File Use Karna

@font-face tab use hota hai jab font file project ke andar locally rakhi ho. Example: .woff2 file assets/fonts folder mein hai. Is method mein tum font ka custom naam define karte ho, file path dete ho, phir normal font-family ki tarah use karte ho.

woff2 modern web font format hai aur mostly recommended hai kyunki compressed hota hai. Large font files website loading slow kar sakti hain, isliye unnecessary font weights aur styles avoid karo.

font-face.css
@font-face {
    font-family: 'MyCustomFont';
    src: url('fonts/my-font.woff2') format('woff2');
    font-weight: 400;
    font-style: normal;
}

body {
    font-family: 'MyCustomFont', Arial, sans-serif;
}

3. font Shorthand Property

font shorthand se multiple font properties ek line mein likh sakte hain. Lekin order important hota hai.

Shorthand useful hai jab tum compact CSS likhna chahte ho. Lekin beginners ke liye separate properties zyada readable hoti hain. Jab debugging kar rahe ho, separate font-size, font-weight, line-height likhna better hota hai.

font-shorthand.css
/* Order:
   font-style font-variant font-weight font-size/line-height font-family
*/

p {
    font: italic small-caps 600 18px/1.6 Arial, sans-serif;
}

/* Common practical shorthand */
.card-title {
    font: 700 24px/1.2 'Poppins', sans-serif;
}
■ Warning: Font shorthand use karte time font-size aur font-family required hote hain. Agar missing hue toh rule invalid ho sakta hai.

4. Practical Typography System

Real website mein typography random values se nahi banani chahiye. Ek system banao: body text ka size fixed karo, headings ke sizes decide karo, line-height consistent rakho, aur colors variables se manage karo. Isse poori website professional aur consistent lagti hai.

typography-system.css
body {
    font-family: 'Poppins', Arial, sans-serif;
    font-size:   16px;
    line-height: 1.6;
    color:       #222;
}

h1 { font-size: 3rem;    line-height: 1.1; font-weight: 700; }
h2 { font-size: 2rem;    line-height: 1.2; font-weight: 700; }
h3 { font-size: 1.5rem;  line-height: 1.3; font-weight: 600; }
p  { font-size: 1rem;    line-height: 1.7; }
small { font-size: 0.875rem; }

5. Typography Hierarchy - User Ki Nazar Guide Karna

Typography ka kaam sirf beautiful text banana nahi hai. Iska main kaam user ki eye guide karna hai: pehle heading dikhe, phir subheading, phir paragraph, phir button/action. Isko visual hierarchy bolte hain.

Element Typical Style Reason
h1 Largest, bold, tight line-height Page ka main topic instantly clear ho
h2 Large, bold/semi-bold Sections clearly divide ho
h3 Medium, semi-bold Sub-section readable ho
p 16px, normal weight, 1.6 line-height Long reading comfortable ho
small 14px ya 0.875rem Meta info, helper text, captions
button Medium weight, clear color contrast Action clearly visible ho

6. Common Typography Mistakes

MISTAKE
Har heading ka random size.
Paragraph line-height too tight.
Ek page mein 4-5 fonts.
Low contrast gray text.
Button text too small.
FIX
3-5 font sizes ka scale banao.
Paragraph line-height 1.5-1.8 rakho.
1-2 fonts enough hain.
Contrast clearly test karo.
Buttons 14-16px readable rakho.
■ Golden Rule: Design mein font, text aur color alag-alag topics lagte hain, lekin real UI mein yeh saath kaam karte hain. Good typography = readable font + proper spacing + strong hierarchy + clear contrast.

Best Practices - Yaad Rakhna

DO
